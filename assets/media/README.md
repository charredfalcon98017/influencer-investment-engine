# App media

All six PNGs and the WebM were captured from the actual running application at 1440 × 1080 on 11 September 2026. No mock screens, generated artwork, substituted values or reconstructed animation were used. The cover is a direct capture of the Allocation content region. Five full-screen captures show Brief, Compare, B’s Decision, D’s Decision and Allocation.

[Watch the recording](walkthrough.webm). It is a continuous **86.48-second silent VP8 WebM**, including navigation and reading pauses. Open in a WebM-capable browser, or download the file if GitHub shows a download page. The README walkthrough supplies the explanation; this file is real demo media, separate from the written demo script.

Sequence: Brief → Compare → A (missing geography) → B (invest) → D (conditional test) → Allocation. Captures taken during the recording add a few seconds beyond the 75 seconds of planned reading pauses.

| Asset | Content |
| --- | --- |
| `hero.png` | Actual Allocation content, including amounts and limitations |
| `01-brief.png` | Budget, market, margin, target and demo boundary |
| `02-compare.png` | Full reach ranking and all investment verdicts |
| `03-decision-b.png` | B’s ₹32,000 investment and 40-order hurdle |
| `04-decision-d.png` | D’s ₹16,000 conditional test and verification condition |
| `05-allocation.png` | Full Allocation screen: ₹48,000 recommended, ₹52,000 held |
| `walkthrough.webm` | Continuous browser recording of the complete decision story |

[Machine-readable manifest](manifest.json) records byte sizes, SHA-256 hashes and duration. `npm run qa:packaging` checks it against the physical files and README references. The recording is a demonstration of a synthetic scenario, not live campaign evidence.
